# Boxi
Hi, this is a game I've been making in my free time. I hope you enjoy!

## Help

### How to play
Use the player to push around the box, and get it to the goal. Getting the box to the goal gives a point. The goal is to get as many points as you can.

### Controls
- Up - `Up Arrow` or `W`
- Left - `Left Arrow` or `A`
- Down - `Down Arrow` or `S`
- Right - `Right Arrow` or `D`
- Cycle Color
    - Previous - `[`
    - Next - `]`
